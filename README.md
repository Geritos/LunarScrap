# Lunar Scrap

Introduces Lunar tier Scrap, a new resource specifically designed for use in Cleansing Pools. Beyond the new item, it expands gameplay flexibility by allowing you to scrap unwanted Lunar items and enables Drifter to utilize her *Tinker (R)* ability on the Lunar tier.

## Compatibility

These mods are not required for Lunar Scrap to work, however they enhance the experience.

- [Lunar Printer](https://thunderstore.io/package/Geritos/Lunar_Printer/): My other mod, which adds Lunar Printers to the game. It goes hand in hand with the this mod.

- [MoreStats](https://thunderstore.io/package/RiskOfBrainrot/MoreStats/): Drifter's passive increases your luck for each Lunar Scrap you hold.
The amount of luck per Scrap can be configured in config.

- [LookingGlass](https://thunderstore.io/package/DropPod/LookingGlass/): If both MoreStats and LookingGlass are installed, the added luck from Lunar Scraps will now be visible in the UI when playing as Drifter. You will also receive a Scrap buff icon (just like with the other tiers of Scrap).
